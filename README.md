# Адвокатское бюро «Этлегис» — Десятая концепция «Синтез»

Официальный сайт адвокатского бюро «Этлегис» (Концепция 10: Бутиковая эстетика «Синтез» с интерактивным 3D-знаком и адаптивной кинематикой).

- **Демо / GitHub Pages:** [https://max1m369.github.io/etlegis/](https://max1m369.github.io/etlegis/)

## Особенности концепции
- Интерактивный кинетический 3D-символ на Three.js с физической моделью освещения, трансформациями при скролле между смысловыми блоками и интерактивным откликом на курсор.
- Скульптурная трансформация знака в секции «О бюро» в информационный кристалл / знак сведений.
- Автономная чистая статическая архитектура с относительными путями для стабильной работы на GitHub Pages.
- Полный набор ключевых страниц: О бюро, Практики, Команда, Кейсы, Блог, Контакты, Политика конфиденциальности, Согласие на обработку ПД.
