# Технический отчёт и архитектурный анализ Админ-Панели «Etlegis Studio»

## 1. Общие характеристики системной архитектуры

- **Движок и CMS**: **Payload CMS 3.0** (Headless CMS для Next.js 15 App Router).
- **Фреймворк фронтенда студии**: **Next.js 15.4** (React 19).
- **База данных**: Поддержка гибридного адаптера:
  - **SQLite** по умолчанию (`local.db` локально через `@payloadcms/db-sqlite`).
  - **PostgreSQL** при указке `DATABASE_URI` (`@payloadcms/db-postgres`).
- **Стилизация и UI**: Tailwind CSS v3, TipTap Editor (для WSIWYG редактора статей), DND Kit (для drag-and-drop сортировки адвокатов и коллекций).
- **Обработка медиа**: **Sharp** (оптимизация и нарезка превью изображений) и S3 хранилище (пакет `@payloadcms/storage-s3`).

## 2. Структура коллекций данных (Collections & Globals)

Админ-панель полностью отражает предметную область Адвокатского бюро Etlegis и включает следующие коллекций:

1. **`Practices` (Практики)**: Управление 4 базовыми направлениями (Уголовная защита, Корпоративные споры, Налоговый консалтинг, Банкротство) со слагами, иконками и описаниями.
2. **`Services` (Услуги)**: Детализированные услуги с привязкой к конкретным практикам (`practiceId`), описанием проблем доверителя и решением.
3. **`Cases` (Кейсы и судебные победы)**: Судебные дела с суммами исков (напр., `1,2 млрд ₽`), инстанциями, описью стратегии и привязкой к юристам.
4. **`Employees` (Адвокаты и партнеры)**: Профили партнеров, стаж, образование, био, фото 3:4, привязанные практики и кейсы.
5. **`Posts` (Публикации и Блог)**: Экспертная аналитика и статьи с категориями, датами, временем чтения и WSIWYG-контентом.
6. **`Leads` (Заявки и Лиды)**: Данные обращений из форм «Обсудить ситуацию» (ФИО, защищенный телефон, суть вопроса, UTM-метки, статус обработки).
7. **`Bookings` & `Slots`**: Календарь онлайн-записи и доступных слотов для консультаций.
8. **`Awards`**: Награды и рейтинги бюро (Pravo-300, Коммерсантъ, Право.ru).
9. **`AuditLog`**: Журнал действий администраторов (аудит изменений).
10. **`AdminUsers` & `Sessions`**: Авторизация, сессии, разграничение прав (RBAC: Admin, Editor).
11. **`Settings` (Глобальные настройки)**: Реквизиты бюро, телефоны, мессенджеры, SEO-метаданные по умолчанию.

## 3. Спецификация API и интеграция с основным сайтом (`/`)

Админ-панель предоставляет стандартизированные API эндпоинты:

- **REST API Payload**: `/api/payload/*`
  - `/api/payload/practices` — получить список практик.
  - `/api/payload/employees` — получить список адвокатов.
  - `/api/payload/cases` — получить список кейсов.
  - `/api/payload/posts` — получить список статей.
- **Интеграция лидов**: `/api/booking` и `/api/lead` (обработка формы «Обсудить ситуацию»).
- **Админ-интерфейс**: `/admin` (или Studio панель по адресу `/studio`).

---

## 4. Рекомендация по бесшовной интеграции

Для подключения основного сайта к админ-панели:
1. Вызовы функций в `lib/data/queries.ts` при наличии подключенного `DATABASE_URI` или API читают живые данные из базы Payload (`local.db` или Postgres).
2. Формы модального окна `ConsultationModal` отправляют POST-запрос на `/api/payload/leads` (или `/api/lead`), создавая новую запись в коллекции **`Leads`** админки.
