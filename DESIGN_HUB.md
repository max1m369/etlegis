## ⚡ 2. Инструкция по переключению между версиями дизайна

### 🔹 1. Вернуться к оригинальному сайту (v1):
```bash
git checkout baseline-original
```

### 🔹 2. Работать над текущим редизайном (v2):
```bash
git checkout design/v2-redesign
```

### 🔹 3. Открыть/посмотреть альтернативный вариант (v3):
```bash
git checkout design/v3-alternative
```

---

## 🔗 3. Схема работы локального окружения (v2)

* **Основной сайт (Дизайн v2):** `http://localhost:3000`
  * Подключен к бэкенду Payload CMS через API (`/api/payload/cases`).
  * Все кейсы, опубликованные в админке, сразу отображаются здесь.
* **Админ-панель (Studio):** `http://localhost:3001/studio`
  * При переходе на `http://localhost:3001/` автоматически перенаправляет в админку Studio.
  * Управление кейсами, практиками, сотрудниками, услугами и заявками.

---

## 🛡️ 4. Правила разработки
1. Все изменения дизайна делаются в ветке `design/v2-redesign`.
2. Файлы на сервер VPS **не деплоятся без вашей прямой команды**.
3. Все 3 варианта дизайна надежно зафиксированы в Git.
